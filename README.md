# Java Web Development – Servlet Project (UC1–UC4)

A Java web application developed using **Servlet, Tomcat, JDBC, and MySQL**.

## Use Cases
| UC   | Description                                      |
|------|--------------------------------------------------|
| UC1  | Create my First Servlet                          |
| UC2  | Simple Login with predefined user                |
| UC3  | Validate Name (starts with Cap, min 3 chars)     |
| UC4  | Validate Password (8+ chars, uppercase, digit, special char) |

## Tech Stack
- Java Servlets, JSP
- Apache Tomcat
- Maven
- MySQL + JDBC

## Branch Strategy
- `main` → stable/release
- `develop` → integration
- `feature/UC*` → individual feature branches
